# 小红书爆款编导 Skill

目标：让用户在信息流里点击，在笔记里读完/滑完、收藏，并能在未来搜索时再次找到。

本 Skill 只负责编导决策，不代写完整正文。

在 Content OS “成长（给初稿）”节点内部执行：

`小红书编导报告 → 写作者初稿`

---

## 一、强制读取

每次调用必须完整读取：

- `references/lv-bai-xhs-benchmark.md`

只学习公开方法，不复制标杆的标题、笔记和账号身份。

---

## 二、小红书平台逻辑

小红书同时有两条流量路径：

### 推荐流

`封面/标题点击 → 首屏停留 → 滑动/阅读 → 收藏评论`

### 搜索流

`明确问题 → 长尾词匹配 → 内容解决问题 → 收藏/复访/决策`

小红书编导优先级：

`搜索意图 → 封面标题点击 → 看见即能用 → 收藏资产 → 真实体验 → 长尾复访`

不是抖音的逐秒完播逻辑。

---

## 三、吕白式编导决策

### 1. 禁止自我陶醉

先写：

> 用户为什么要搜/点这篇，而不是作者为什么想表达？

作者经历只负责证明，不负责占满正文。

### 2. 爆款母题重复

创作前检查：

1. 同搜索词下的高表现选题反复出现什么？
2. 哪种封面信息一眼能读懂？
3. Top评论还在追问什么？
4. 本篇只升级哪个变量？

不照抄内容，重复经过验证的用户问题。

### 3. 专一

一篇只服务一个：

- 人群。
- 场景。
- 痛点。
- 搜索意图。

### 4. 给收藏理由

笔记必须留下一个以后能用的资产：

- 清单。
- 判断标准。
- 步骤。
- 对比。
- 模板。
- 截图卡。
- 路线/资源。

纯情绪帖也要提供一句可转述的身份表达。

---

## 四、输入

必须读取：

1. 用户选题。
2. 当前选中的芽。
3. 当前选中芽的粉色标记。
4. 用户真实经历。
5. 图片与截图素材。
6. 目标搜索词或用户问题。
7. 账号定位。

若没有目标搜索意图，先从选题拆出：

`人群 + 场景 + 痛点/任务`

---

## 五、编导步骤

### Step 1｜确定搜索意图

选择一种：

- 想知道。
- 想学会。
- 想比较。
- 想避坑。
- 想做决定。
- 想表达自己的感受。

### Step 2｜确定笔记承诺

一句话写清：

> 点开并收藏后，用户以后能用它完成什么？

### Step 3｜选择内容形态

- 图文卡片：清单、步骤、判断、对比。
- 真实照片+长文：经历、身份、情绪表达。
- 视频：需要动作、过程、现场证明。
- Live Photo/混剪：材料本身有运动价值。

不因平台扶持盲目选视频。

### Step 4｜封面设计

封面只负责一个信息：

- 谁的问题。
- 什么场景。
- 具体结果/冲突。

要求：

- 手机缩略图可读。
- 1–2行主文案。
- 真实素材优先。
- 不把正文摘要塞满封面。

### Step 5｜标题设计

标题必须：

- 20字以内优先。
- 自然包含核心搜索词。
- 明确人群/场景/痛点。
- 给点击理由，不把答案全部讲完。

禁止关键词堆砌和抖音式空悬念。

### Step 6｜首屏与正文

首屏100字内：

- 复述用户正在经历的具体问题。
- 给核心结论或结果。
- 告诉用户这篇能拿走什么。

正文：

`真实场景 → 证据 → 机制 → 可收藏资产 → 个人边界`

### Step 7｜卡片结构

图文笔记每页只完成一项任务：

1. 封面。
2. 问题/结果。
3. 证据。
4. 方法或判断。
5. 示例。
6. 总结卡。

页与页之间有继续滑动的理由。

### Step 8｜搜索与评论

报告必须给出：

- 核心词。
- 2–4个长尾词。
- 评论区自然问题。
- 后续系列词。

## 六、小红书100分评分

| 维度 | 分值 |
|---|---:|
| 搜索意图清晰 | 20 |
| 封面标题点击 | 20 |
| 收藏资产 | 20 |
| 真实证据 | 15 |
| 图文可扫读 | 15 |
| 评论与系列长尾 | 10 |

评级：

- 80–100：高潜力。
- 65–79：中高潜力。
- 50–64：中潜力。
- 低于50：先补搜索意图或资产。

不预测具体点赞、收藏和粉丝。

## 八、质量门禁

- [ ] 已读取小红书主标杆参考。
- [ ] 搜索意图明确。
- [ ] 一篇只服务一个人群场景。
- [ ] 封面只传递一个信息。
- [ ] 标题自然包含核心词。
- [ ] 有明确收藏资产。
- [ ] 真实经历只做证据，不自我陶醉。
- [ ] 图文能快速扫读。
- [ ] 评论区有自然问题。
- [ ] 能形成长尾系列。
- [ ] 未照搬标杆笔记。
