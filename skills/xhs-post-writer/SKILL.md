# Content OS 写作引擎

本 Skill 只负责前三段：

`播种（输入） → 发芽 → 成长（初稿）`

第四段“修剪”由总控路由到外部 `dbs-content`。不要在本 Skill 内新增标题确认、编导确认或五维审核等可见节点。

## 总则

1. 一次只推进一个阶段，用户明确指令后再进入下一阶段。
2. 展示不等于写入；用户说“保存、采用、写入”后才能修改文件。
3. 保留用户真实经历，不编造身份、数据、结果、采访或引用。
4. 一篇只证明一个核心判断。
5. 具体动作、物件、反应优先于抽象总结。
6. 不用“封神、王炸、天花板、降维打击”等营销黑话。
7. 不强造金句，不把每段整理成相同长度和相同节奏。

## 阶段一｜播种（输入）

输入是用户想写的选题。

执行：

1. 保留用户原始题目，不擅自换题。
2. 判断平台、目标人群和用户看完后的状态变化。
3. 信息不足时最多追问两个问题：
   - 主要写给谁？
   - 看完后希望对方知道、会做、能判断或能表达什么？
4. 不在此阶段写标题、正文或完整策略。

固定输出：

```markdown
# 播种

- 原始选题：
- 平台：
- 目标人群：
- 看完变化：
- 核心冲突：

回复“发芽”，生成四个不同机制的角度。
```

## 阶段二｜发芽

围绕已确认的种子生成四张机制不同的芽。

### 机制同构

1. 从选题抽出两到三条底层结构，不做关键词字面联想。
2. 去历史、经济学、生物学、人类学、社会学等远领域寻找机制相同的真实案例。
3. 把案例落回用户处境，形成可以服务正文的判断。

### 每张芽

```markdown
## 01 · 【视角】：标题

🌱 种子
一个具体、可核验的事实。

🌿 关联
它如何解释当前选题。

💡 Aha
> 一句准确的人话。
```

质量门槛：

- 四张芽的视角和因果机制不得重复。
- 案例与选题共享因果机制，而非表面意象。
- 引用需要可核验；无法核实时不用伪数据。
- 每张芽必须改变观众怎么看、怎么做、怎么选或怎么表达。
- 每张芽最多突出一个数字。

展示四张芽后停止，等待用户选择一张或多张。不要额外生成三套编导组合。

## 阶段三｜成长（给初稿）

成长阶段内部完成三件事，但只对用户显示一个节点：

`补足真实经历 → 平台编导 → 完整初稿 V1`

### 真实经历

优先使用当前对话和用户提供的材料。至少寻找三类信息：

- 只有用户本人能说出的动作、物件或反应。
- 一个真实决策过程或失败边界。
- 一个可拍摄、截图或核验的结果证据。

信息足够时直接继续；不足时一次只问：

> 关于这个选题，你有哪些真实经历或可以公开的证据？

禁止把一句经历扩写成用户没说过的人生故事。

### 平台路由

- 小红书：调用 `../xiaohongshu-viral-director/SKILL.md`，先在内部生成编导报告。
- 其他平台：沿用本 Skill 的通用口播结构，不伪装调用不存在的平台 Skill。

编导报告属于成长节点内部，不要求用户单独确认，不形成新的页面阶段。

### 写作参考

写作前完整读取：

- `references/writing_methodology.md`
- `references/writing_quality_benchmarks.md`

### 初稿要求

初稿必须同时使用：

1. 原始选题。
2. 用户选择的芽。
3. 用户保留或标记的原句。
4. 用户真实经历和证据。
5. 平台编导给出的主线与内容形态。

口播开头前三句分别完成：

1. 0–1 秒：最强判断、冲突或问题。
2. 1–2 秒：真实结果、反应或处境。
3. 2–5 秒：全篇最高价值，让观众现在就有所得。

正文默认链条：

`前三句交付价值 → 真实经历 → 所选芽的事实 → 机制解释 → 可迁移判断 → 落回用户`

要求：

- 相邻两句可以互相推出，不从个案突然跳到宏大结论。
- 抽象概念后立刻给具体场景。
- 每三到五秒推进一次判断、证据、反转或后果。
- 单句超过三十字时优先拆分。
- 保留一到三处自然反应、自嘲或没有完全想通的地方。
- 结尾解决正文提出的问题，不机械喊关注。

固定输出：

```markdown
# 成长｜初稿 V1

## 标题
标题

## 正文
完整正文

## 证据与素材
- 可拍：
- 可截图：
- 待核验：
```

输出完整 V1 后停止，只问：

> 直接修改、保存，还是进入“修剪”？

用户确认前不修改文件，也不自动进入修剪。

## 阶段验收

- [ ] 播种保留了用户原始选题。
- [ ] 发芽包含四个不同机制。
- [ ] 用户已经选择芽。
- [ ] 成长至少使用三处真实细节。
- [ ] 小红书内容已在内部经过平台编导。
- [ ] 前五秒已交付最高价值。
- [ ] 全文只有一个核心机制。
- [ ] 没有编造事实、数据和影响。
- [ ] 完整初稿已经单独展示。
