# AI Content Workflow Skills

一套给短视频/小红书创作者的人机协作文案工作流——不是"一键生成终稿"，而是每一步都保留你的判断权，最终产出能直接对着镜头念、没有AI味的口播稿。

---

## ✨ 核心特点
- **严格卡短视频节奏**：内置 0-1s炸场→1-2s亮结果→2-5s拉留存 的三段式开头规则，拒绝慢热
- **跨领域视角找创意**：发芽阶段给你4个普通人想不到的跨领域认知角度，不是陈词滥调
- **双角色创作防AI味**：编导先搭骨架节奏，写作者再填血肉，不会出来工整但没灵魂的AI稿
- **分轮确认不越权**：每一步都先展示给你确认，不会偷偷改稿、跳步生成
- **五维审核只给建议**：审核只出原句→诊断→改句，最终改不改全由你决定

## 🚀 30秒安装
在你的 Trae 项目根目录执行这三行命令就装好了：
```bash
git clone https://github.com/lindixu6-hash/ai-content-workflow-skills.git
mkdir -p .trae/skills
cp -R ai-content-workflow-skills/skills/* .trae/skills/
```

安装后目录结构：
```text
.trae/skills/
├── xhs-post-writer/   # 四阶段写稿Skill
│   └── SKILL.md
└── xhs-5d-review/     # 五维审核Skill
    └── SKILL.md
```

其他支持 `SKILL.md` 规范的 Agent 环境也可以用，把两个目录复制到对应 Skill 目录即可。

## 🎬 四阶段工作流
```
1. 播种 → 你说主题和真实经历，AI帮你把模糊想法理清楚
   ↓
2. 发芽 → AI给出4个跨领域认知角度+编导3种组合建议，你选最有感觉的
   ↓
3. 成长 → 先出编导思路骨架（带时间轴），你确认后再出完整V1口播稿
   ↓
4. 修剪 → 你说"开始修剪"，AI从5个维度给诊断和改句建议，你决定改哪些
```

**绝对不跳步**：没确认编导思路不会出稿，没确认V1不会主动审核。

## 📝 最短使用示例
直接复制这段对话就能用：
```text
你：开始播种：我让AI帮我买了三件衣服，每件都很喜欢。

AI：（确认核心信息后）回复「发芽」进入下一环节。

你：发芽

AI：（给出4个跨领域视角+3种编导组合建议）回复A/B/C选组合。

你：A，开始成长。

AI：（先出编导时间轴骨架）回复「确认」出V1。

你：确认

AI：（输出完整可直接朗读的口播稿V1，停下等你）

你：开始修剪。

AI：（输出5张审核表，每张都有原句、问题、改句A、改句B）
```

### 只有初稿，想直接审核
不用从头走流程，直接说：
```text
请用xhs-5d-review审核这篇稿件，只出五张审核表，不要直接改稿。
```

## 📦 两个Skill分别做什么
| Skill | 适用场景 | 核心输出 |
|---|---|---|
| `xhs-post-writer` | 有选题、经历或模糊想法，想从头写口播稿 | 四阶段推进，最终产出可直接念的口播稿 |
| `xhs-5d-review` | 已经有初稿，想诊断问题、去AI味 | 核心逻辑、结构、AI味、标题Hook、共鸣传播五张诊断表+具体改句 |

---

## ⚠️ 核心规则（不用记，AI会自动遵守）
1. **开头硬节奏**：0-1s炸场，1-2s亮真实结果，2-5s给观众明确好处拉留存，核心方法第6秒再讲
2. **去AI味铁律**：不用"全中/封神/天花板"等营销黑话，不用"真正的X不是A是B"这类空排比，说人话
3. **用户有最终裁决权**：标题、角度、稿子改不改全听你的，AI只给建议不替你做决定
4. **展示不等于写入**：所有稿子先在对话里展示，你说"保存"才会写入文件
5. **隐私保护**：不会主动泄露你的个人信息、职业、学校等隐私内容

## ❓ 常见问题
**Q：Skill没自动触发怎么办？**
A：确认文件放在`.trae/skills/`目录下，直接说"请使用xhs-post-writer开始播种"即可。

**Q：我只想写小红书图文/抖音口播，不做视频可以吗？**
A：完全可以，两个Skill只负责文案部分，视频工具都是可选的。

**Q：出来的稿子还是有AI味怎么办？**
A：直接说"用xhs-5d-review专门查AI味"，审核会把所有AI腔句子挑出来给改句。
